*   **`train/`**
    Contains the training source code and the required dataset, using the abdominal CT dataset as an example. The main training script is located at:
    `./train/train_APFNet.py`

*   **`test_example/`**
    Provides the evaluation scripts along with two sample test cases from the abdominal CT dataset. The testing script is located at:
    `./test_example/test_onecase_abdomenCT.py`

*   **`results/`**
    Includes the quantitative benchmark results (in Excel format) comparing our proposed method against various baselines, as well as the pre-trained model weights (`.pth` files) evaluated across different datasets.
